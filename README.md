# Учёт расходов

Локальная страница для учёта личных расходов за месяц. Работает без установки и хранит данные только в браузере.

## Что умеет

- добавлять трату с суммой, категорией, датой и необязательным комментарием;
- показывать новые траты сверху списка;
- считать итог только за текущий календарный месяц;
- сохранять траты после обновления страницы через `localStorage`;
- проверять сумму и не сохранять пустое или неверное значение;
- форматировать целые суммы в тенге: `15 000 ₸`.

## Как открыть

Откройте `index.html` двойным щелчком. Интернет и установка программ не нужны.

## Как проверить

1. Добавьте траты `5 000`, `2 500` и `12 000` с датами текущего месяца.
2. Убедитесь, что новые траты появляются сверху, а итог равен `19 500 ₸`.
3. Обновите страницу клавишей F5 — траты и итог должны остаться.
4. Добавьте трату с датой прошлого месяца — она должна появиться в списке, но не менять текущий итог.
5. Попробуйте пустую сумму, текст, дробное число и `0` — запись не должна сохраниться, под полем должна появиться подсказка.
6. Проверьте страницу в окне шириной 375 px: поля и кнопка должны оставаться удобными и не выходить за экран.
