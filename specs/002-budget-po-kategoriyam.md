# Бюджет по категориям

## Для кого и зачем

Для одного человека, который хочет заранее распределить месячный бюджет и видеть, укладываются ли расходы в заданные лимиты. Функция нужна, чтобы по каждой категории сравнивать лимит с фактическими тратами и вовремя замечать перерасход.

## Что должно быть

- Отдельный блок «Бюджет месяца» для текущего календарного месяца.
- Поля лимитов для существующих категорий: Еда, Транспорт, Дом, Другое.
- Кнопка «Сохранить бюджет».
- Лимиты сохраняются отдельно для каждого календарного месяца в `localStorage` и остаются после F5.
- Общий бюджет месяца равен сумме лимитов всех категорий.
- Для каждой категории показаны лимит, сколько потрачено за текущий месяц и сколько осталось.
- В расчёт потраченного входят только траты текущего календарного месяца и соответствующей категории.
- Если траты не превышают лимит, остаток равен разнице между лимитом и тратами.
- Если траты превышают лимит, вместо отрицательного остатка показано предупреждение «Перерасход: …» с суммой превышения.
- Если лимиты текущего месяца ещё не сохранены, показываются нулевые значения и понятная подсказка настроить бюджет.
- После добавления новой траты показатели бюджета обновляются сразу.
- Все денежные значения показываются целыми тенге с пробелами между тысячами; `NaN` не показывается.

## Примеры

- Лимиты `50 000` на еду, `20 000` на транспорт, `30 000` на дом и `10 000` на другое → общий бюджет `110 000 ₸`.
- При лимите на еду `50 000 ₸` и тратах на еду `35 000 ₸` показано: потрачено `35 000 ₸`, осталось `15 000 ₸`.
- При лимите на транспорт `20 000 ₸` и тратах на транспорт `22 500 ₸` показано предупреждение: «Перерасход: 2 500 ₸».
- Трата прошлого месяца не меняет показатели бюджета текущего месяца.

## Ограничения

- Только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Данные хранятся только в браузере и не отправляются в интернет.
- Используются существующие четыре категории; добавление и удаление категорий в эту функцию не входит.
- Лимит должен быть целым неотрицательным числом. Пустое, дробное или неверное значение не сохраняется, рядом с полем показывается подсказка.
- Значение `0` допустимо и означает нулевой лимит категории.
- Русский интерфейс, поля и кнопки не меньше 44 px.
- Блок бюджета и карточки категорий не выходят за экран на ширине 375 px.
- Существующее добавление трат, месячный итог и сохранение трат должны продолжать работать.

## Готово, когда

- Для каждой из четырёх категорий можно сохранить корректный месячный лимит.
- Пустой, дробный, отрицательный или неверный лимит не сохраняется и сопровождается подсказкой.
- Общий бюджет точно равен сумме четырёх лимитов.
- Потраченная сумма каждой категории учитывает только её траты текущего месяца.
- Остаток и перерасход пересчитываются сразу после сохранения лимитов и после добавления траты.
- При превышении лимита видно предупреждение и точную сумму перерасхода; отрицательная сумма остатка не показывается.
- После F5 лимиты и рассчитанные показатели остаются корректными.
- Бюджеты разных календарных месяцев не смешиваются.
- Проверка из README для трат `5 000`, `2 500` и `12 000` по-прежнему даёт итог `19 500 ₸`.
- Сценарии работают при открытии `index.html` двойным щелчком и на ширине 375 px.

## Шаги

- [ ] Шаг 1. На экране появится блок «Бюджет месяца» с четырьмя полями лимитов, общим бюджетом и кнопкой сохранения. Проверка: 1) ввести четыре лимита и сохранить; 2) нажать F5 и проверить сохранённые значения; 3) очистить одно поле, сохранить и увидеть подсказку.
- [ ] Шаг 2. В блоке появятся показатели «Лимит», «Потрачено» и «Осталось» для каждой категории. Проверка: 1) добавить траты текущего месяца в две категории; 2) сверить потраченное и остаток этих категорий; 3) добавить трату прошлого месяца и убедиться, что показатели не изменились.
- [ ] Шаг 3. Появится заметное предупреждение о перерасходе, будет завершена адаптация для ширины 375 px и обновлён README. Проверка: 1) добавить трату больше лимита и сверить перерасход; 2) нажать F5 и проверить сохранность показателей; 3) открыть страницу на ширине 375 px и выполнить проверку из README.
